# RetireWeb Frontend

Next.js 기반 프론트엔드 애플리케이션

## 시작하기

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

### 빌드

```bash
npm run build
npm start
```

## 환경 변수

`.env.local` 파일을 생성하고 다음 변수를 설정하세요:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## 주요 기능

- 반응형 UI (모바일/태블릿/데스크톱)
- 로그인/회원가입
- AI 챗봇
- 커리어 컨설팅
- 우울 수치 모니터링
- 대화 기록

## 기술 스택

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
